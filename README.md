## What happens?

GitHub Actions appends one love declaration to [MIKARIN.md](MIKARIN.md) each day at approximately **06:17 JST**, then commits it to the default branch.

> みかりん！！！！！！

## Manual run

Go to **Actions → Daily Mikarin → Run workflow**.

Scheduled runs may be delayed or skipped by GitHub. The script prevents duplicate entries for the same Japan-local date when run more than once.
